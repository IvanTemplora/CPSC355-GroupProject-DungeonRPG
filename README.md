Welcome to our CPSC355 Project - DUNGEON RPG

Files and usage:
 - main.asm: Contains the main game loop and functions to run the game and complete

 - player.asm: Contains functions regarding the player with includes movement, stats such as health, damage, and armor. It will pull from inventory and combat files to attack and use items
 - combat.asm: Contains functions with combat such as attacking and damage numbers.
 - level.asm: Contains the dungeon levels and the behavior for each level.
 - inventory.asm: Contains the functions in regards to items, armor, weapons, etc.
 - util.asm: Contains helper functions such as Random number generation.
 - enemy.asm: Contains the functions regarding the enemy such as their stats and behavior.
